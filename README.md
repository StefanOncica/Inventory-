This is the Inventory app!

It allows the user to define the fields and populate them directly from the terminal.

---

To run this app:

Move to desired folder and paste these comands in your terminal:

1. git clone https://github.com/StefanOncica/Inventory-.git

2. cd Inventory-/

3. uv run inventory

Follow the instructions in the terminal to create/update your inventory.
